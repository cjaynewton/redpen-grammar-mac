# Retail Dark

Redpen's palette, in the same family as warm paper, dark ink and one signature colour.

| Token | Colour | Use |
|---|---|---|
| Night | `#0E1419` | Icon tile, dark surfaces |
| Cream | `#F5EDE2` | Letters on Night |
| Redpen red | `#FF4B3E` | The full stop, the one accent |
| Paper | `#FAF6F0` | Light surfaces |
| Ink | `#1A1816` | Text on Paper |

The icon is a lowercase r in Gloock (SIL Open Font License) followed by a red full stop, on a Night tile. Source drawing: `Resources/Icon/icon-source.html`.
